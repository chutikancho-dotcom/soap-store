# บ้านสบู่ — ตัวอย่างร้านค้าออนไลน์

โปรเจกต์ตัวอย่างสำหรับงานสร้างหน้าเพจขายสบู่อย่างน้อย 2 SKU

## โครงสร้างไฟล์
- `index.html` หน้าเว็บร้านค้า
- `public/style.css` รูปแบบหน้าเว็บ
- `public/app.js` ตะกร้าสินค้าและแบบฟอร์มสั่งซื้อ
- `data/products.json` ข้อมูลสินค้าสำหรับหน้าเว็บ
- `public/images/` โฟลเดอร์เก็บรูปสินค้า
- `ข้อมูลสินค้า_นำเข้าGoogleSheets.xlsx` ตารางตั้งต้นสำหรับเปิดใน Google Sheets

## ก่อนส่งงาน
1. แก้ชื่อร้าน ชื่อสินค้า รายละเอียด ราคา จำนวนคงเหลือ และรูปภาพให้ตรงกับสินค้าจริง
2. ข้อมูลทั้งหมดในชุดนี้เป็นข้อมูลตัวอย่าง ไม่ใช่ข้อมูลสินค้าจริง
3. เว็บไซต์นี้เป็นเดโม: คำสั่งซื้อแสดงผลบนหน้าเว็บและ console เท่านั้น ยังไม่เชื่อมฐานข้อมูล/ระบบชำระเงิน/ขนส่งจริง

## เปิดดูในเครื่อง
ใช้ VS Code เปิดโฟลเดอร์นี้ แล้วรันด้วย Live Server หรือ deploy เป็น Static Site

## อัปโหลด GitHub
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด โดยคงโครงสร้างเดิม
3. ตรวจว่า `index.html`, `data/`, `public/` อยู่ระดับบนสุดของ repository

## Deploy บน Vercel
1. เข้า Vercel แล้วเลือก Add New → Project
2. Import repository จาก GitHub
3. Framework Preset เลือก Other
4. Build Command เว้นว่าง และ Output Directory ใช้ `.`
5. กด Deploy แล้วเปิด URL ที่ Vercel สร้างให้

## ใช้ Google Sheets
อัปโหลด `ข้อมูลสินค้า_นำเข้าGoogleSheets.xlsx` ไป Google Drive แล้วเลือก Open with Google Sheets จากนั้นแก้ข้อมูลให้ตรงกับสินค้า
